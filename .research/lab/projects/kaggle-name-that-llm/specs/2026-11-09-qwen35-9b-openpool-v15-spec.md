# Qwen3.5-9B text-classifier Open Pool v15 candidate

## Hypothesis and evidence limits

An anonymous comment in Kaggle Discussion [754860](https://www.kaggle.com/competitions/name-that-llm/discussion/754860) claims a single, unquantized Qwen3.5-9B model scored public BA `0.649`. The comment does not identify its author, data, validation, revision, training recipe, or runtime. Treat it only as a lead. The public model is worth a local independent test because the claim is competitive with the strongest individual components in the Anto Pil OOF screen; it is not a reproducible result and this spec does not reuse external probabilities.

Official upstream [`Qwen/Qwen3.5-9B`](https://huggingface.co/Qwen/Qwen3.5-9B) is Apache-2.0 and documents a 9B, 32-layer text backbone with hybrid Gated DeltaNet and full-attention layers plus a vision tower. Pin the official repository to revision `c202236235762e1c871ad0ccb60c8ee5ba337b9a`; the public HF API exposes per-file metadata and weight SHA-256 values, and the packaged upstream `LICENSE` is Apache-2.0. Download only this immutable upstream revision and verify all local file hashes before use. Do not use the community Kaggle mirror [`danbth/qwen3-5-9b`](https://www.kaggle.com/models/danbth/qwen3-5-9b): its metadata says MIT, several file sizes differ from the official snapshot, and it provides no content hashes. The exact mirror payload and packaged license are therefore unverified.

## Fixed candidate protocol

- Model: official Qwen3.5-9B post-trained weights, pinned by immutable revision and per-file hashes. Text only; never invoke the vision tower. Use the official `Qwen3_5ForCausalLM`/text-backbone implementation and a new 18-class head over the final non-padding token hidden state. Do not compute vocabulary logits. Tokenization is plain text with the official tokenizer; no prompt IDs, labels, or generated answer enter the input.
- Runtime: isolate this candidate from the active `.venv`. The current Transformers 4.57.1 environment does not expose `Qwen3_5ForCausalLM` or `Qwen3_5TextConfig`. Pin an exact Transformers/PyTorch/PEFT/quantization-free dependency lock that supports the official model before the pilot; record source commit and verify the expected model class and architecture on CPU. Do not change dependencies used by current jobs.
- Adaptation: full unquantized BF16 backbone, frozen except LoRA; no NF4/INT8. Apply rank-16, alpha-32, dropout-0.05 LoRA to all text-block linear projections with exact suffixes `q_proj`, `k_proj`, `v_proj`, `o_proj`, `in_proj_qkv`, `in_proj_z`, `in_proj_b`, `in_proj_a`, `out_proj`, `gate_proj`, `up_proj`, and `down_proj`. Assert the exact matched module list and trainable parameter count before fitting. Do not adapt the vision tower. Train the 18-class head.
- Data: official train plus the registered Open Pool v15 only. For each fold, remove exact normalized official-text duplicates and external rows matching validation prompts under the existing pre-registered char/word TF-IDF threshold 0.40. Sample exactly 2,500 external passages per class (45,000 total) using seed 42. Record exclusions and sampled IDs per fold. No third-party annotation corpus, Anto OOF probability, public adapter, or hidden-test signal.
- Stage 1: one epoch on the external sample, microbatch 1, gradient accumulation 16, AdamW8bit, adapter LR `1e-4`, head LR `1e-3`, weight decay `0.01`, cosine schedule, warmup ratio `0.1`.
- Stage 2: two epochs on official training rows from the other four prompt folds only, microbatch 1, gradient accumulation 16, AdamW8bit, adapter LR `5e-5`, head LR `5e-4`, weight decay `0.01`, cosine schedule, warmup ratio `0.1`. Carry Stage 1 adapter and head forward. Use gradient checkpointing; seed 42; no validation-based early stopping, checkpoint selection, or tuning. Save complete optimizer/scheduler/scaler/RNG state at each epoch for exact resume.
- Max token length 512, fixed truncation, dynamic batch padding. Save raw logits and probabilities; no postprocessing or blend in this candidate.
