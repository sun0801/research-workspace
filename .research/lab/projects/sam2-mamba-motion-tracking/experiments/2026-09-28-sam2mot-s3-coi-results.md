# SAM2MOT再現 S3: Cross-object Interaction の val 25系列結果

## 目的

承認済みspec `specs/2026-09-08-sam2mot-reproduction-spec.md` の S3（Cross-object Interaction、以下 CoI）を実装し、DanceTrack val 25系列で S2 との差分と機構署名を確認する。

機構署名（spec 仮説2・成功基準2）: **IDSW 減・AssA 増・MOTA 増・DetA ほぼ不変**。

## 実験条件

S2（`experiments/2026-09-27-sam2mot-s0-s2-results.md`）と同一。そこに CoI を追加した。

| 項目 | 値 |
|---|---|
| 追加したもの | 衝突検出（mask IoU > 0.8）、Stage 1（logit 差 > 2.0）、Stage 2（直近10フレームの logit 分散）、誤追跡トラック B の現フレームのメモリ除外（A6）、低信頼エントリのメモリ除外（A7、logit ≤ τ_s = 2.0） |
| メモリ除外の実装 | B の `output_dict["non_cond_frame_outputs"][f]` を削除する。SAM2 は以降のフレームの maskmem と obj_ptr をこの dict から集め、無いフレームを飛ばすため、B の現フレームはメモリバンクに入らない。`sam2/` 本体は変更していない |
| 出力 | B の MOT 出力は抑制しない（spec 仮説1: 出力抑制ではなくメモリ除外が本質） |
| ハイパーパラメータ | 論文記載値で固定（mIoU 0.8、logit 差 2、N=10）。調整していない |
| 実装リポジトリ | `/mnt/HDD10TB-2/aburatani/2026_05_aburatani_sam2mot/sam2mot_repro/`。実行ログは `logs/s3_coi.md` |

### 回帰確認

- `--no-coi` で dancetrack0018 / 0005 の出力が S2 と md5 一致した
- 同定だけ行いメモリを変えない条件で、衝突が発生する dancetrack0043（衝突 175）/ 0026（衝突 2,074）の出力が S2 と md5 一致した
- つまり、S2 → S3 の出力の変化は、すべてメモリ除外（A6・A7）から生じている

### 実行

- 25/25 系列成功、形式検証 PASS、所要 2.82 h、peak VRAM 最大 11.21 GiB
- 衝突ペア 11,326（Stage 1 で 9,230、Stage 2 で 2,096 を同定）。CoI によるメモリ除外は 10,934 トラック×フレーム、A7 によるメモリ除外は 8,895
- 生成トラックは 417 → 487（途中追加 250 → 320）。`lost_tolerance` による削除は 88 → 220、出力行数は 268,230 → 231,954

spec「test 追加の発動条件」のうち、次の2つが観測された。

- 符号か順序が論文と食い違う（CoI の寄与が Add を下回る）→ spec の対応表で疑う対象: 実装位置の誤り、特に CoI がメモリバンク書き込み除外になっていない可能性
- CoI で DetA が大きく動く → spec の対応表で疑う対象: CoI が association ではなく検出側に作用している（A3、実装位置）

実装リポジトリのプロトコル（絶対規則1）に従い、差分を論文に合わせるためのハイパーパラメータや A1〜A9 の変更はしていない。

## 解釈（暫定）

### MOTA の改善は、ほぼすべて FP の減少から来ている

MOTA = 1 − (FN + FP + IDSW) / GT で、val の GT box は 225,148。S2 → S3 の ΔMOTA +17.10 を分解すると次のようになる。

| 要因 | 変化 | MOTA への寄与 |
|---|---|---|
| FP | −37,258 | **+16.55** |
| FN | −982 | +0.44 |
| IDSW | −264 | +0.12 |

同じ理由で DetA も +9.19 上がっている。

「同定のみ」の回帰確認から、出力の変化はメモリ除外だけで生じている。メモリを除外されたトラックは次のフレームで logit が下がり、lost が続いて削除されやすくなる。実際、`lost_tolerance` による削除は 88 → 220 に増え、出力行数は 36,276 減った。途中追加で生じた重複トラック（S2 で FP +41,077）が、CoI によって消されている、という経路と整合する。ただし、トラック単位でそれを直接確認したわけではない。

### spec の機構署名「DetA ほぼ不変」は、論文自身の数値と両立しにくい

上の分解から分かるように、IDSW はもともと GT 比で小さい（S2 で 1,162 / 225,148 = 0.5%）。IDSW を 0 にしても MOTA は約 +0.5 しか動かない。論文の ΔMOTA +17.7 は test の値だが、MOTA の式が同じである以上、+17.7 の大半は FP・FN の減少、つまり検出側の変化から来ているはずで、そのとき DetA も動く。

したがって「CoI は association にだけ効き、DetA はほぼ不変」という spec 仮説2は、論文の Table 3 と両立しない可能性が高い。今回の結果で DetA が大きく動いたことは、実装位置の誤りを示すとは限らない。この仮説は spec を書く時点で立てたもので、論文が DetA や AssA の ablation を報告しているわけではない。

### 論文と合わないのは HOTA・AssA・IDF1

MOTA の差分は論文とほぼ一致した一方で、AssA は下がり、ΔHOTA と ΔIDF1 は論文より小さい。系列別に見ると、AssA が大きく下がったのは混雑系列（0026 −12.91、0063 −11.12、0094 −9.07、0041 −8.62）と 0007（−8.69）である。メモリの除外が、正しいトラックの見失いや ID の付け替わりも引き起こしている可能性がある。

切り分けの候補は次のとおり。

- **A7 の分離**: 今回は A6（CoI のメモリ除外）と A7（低信頼フィルタ、8,895 件）を同時に有効にした。A7 は衝突と無関係に全トラックへ作用する。`--no-coi-low-conf-filter` で A6 だけの run を取れば、AssA 低下がどちらによるものかを分けられる
- **A6 の範囲**: 除外は1フレーム単位。Stage 1 の同定が 9,230 と多く、logit が一時的に低いだけの正しいトラックまで B と判定している可能性がある
- **A9**: 論文の "jointly optimizes SAM2's memory frame selection strategy" の中身が未実装

いずれも S3 の設定を変える判断になるため、次段 S4 に進む前にユーザーが決める。
