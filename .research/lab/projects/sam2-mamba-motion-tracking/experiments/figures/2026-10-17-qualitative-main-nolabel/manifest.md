## ④ を10秒にした理由と区間

- 4.6秒版（frame 370–415）を前に伸ばした。frame 414 より後ろを含めると、SAM2 の ID 1 が別の人（GT 5）に移り（414、427 以降）、SAMURAI も見失う（425 以降）ので、後ろには伸ばさなかった。
- frame 314–413: 314–364 は3手法とも ID 1 がこの人物に付く。365–376 は3手法とも一時的に枠がずれる（IoU 0.5 未満）。377 以降は Ours だけ ID 1 が左隣の人（GT 6）に移り、413 まで戻らない（SAM2・SAMURAI は 394–405 で枠が細くなるが同じ人物の上）。
- スライドの説明は秒で書いた（「開始から約6秒後，Ours だけ ID 1 が左隣の人に移る」。377 − 314 = 63 フレーム = 10fps で 6.3 秒）。

## ① を約25秒にした理由と区間

- 0026 と同じように長くしたいというユーザーの希望。系列全体（1203フレーム）だと、SAM2 の ID 0 が frame 1082 以降この人物から外れる（1139–1190 は外れ続ける）ので使わない。
- 1–1081 では、3手法とも1〜数フレームだけ枠が合わなくなる場面がある（frame 19, 338, 395, 417, 424, 427, 929 など。3手法でほぼ同じフレーム）。
- 3手法とも、全員（4人）の ID が一度も GT からずれない（IoU 0.5 以上）最長の区間が frame 676–928（253フレーム、10fps で 25.3 秒）なので、これを使った。
