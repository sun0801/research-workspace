## 段階1 確認（2026-10-29、完了：すべて合格）

結果：SAM2 repo `runs/short_clip/stage1/20261029_p0_360cea8-dirty/`。確認スクリプトはRTX PRO 4500、FP32・決定的な設定。

| 確認 | 結果 |
|---|---|
| ① 初期化直後のEがV3なしと一致（c1） | マスク・クリック・boxとも差0 |
| ② P0の読み込み | V3以外のmissing・unexpected keyなし（初期化の `strict: true` を通過） |
| ③ 3更新の後、学習するもの以外は不変、manifestがB・Cと同じ（c3） | D・Eとも固定したパラメータの変化0、学習対象（D：デコーダ、E：デコーダ＋V3）と学習率・weight decayの除外のグループは前回のB・Cと同じ。V3のweight decayの除外は26個 |
| ④ サンプル列（c2） | D・Eは互いに一致し、同じ確認スクリプトで回した10/27のA・Bとも一致（動画・対象・フレーム・プロンプト・画像の合計値） |
| ⑤ 保存→復元（c10） | D・Eとも全パラメータと出力が一致 |
| ⑥ lossの曲線のスクリプトのF0 | RTX PRO 4500で、以前の結果（`diag_loss_p0_f0`）と200区間・2種類のlossとも完全に一致 |

- 最初のc2では、比べる相手を本番のB・Cにして不一致になった。確認スクリプトは決定的な設定で回すので、補正などのクリックの乱数が本番の起動方法とずれるため（10/27の確認スクリプトのA・B・Cも同じずれ方をしていた）。同じ環境の10/27の確認スクリプトのrunと比べ直して一致した。本番のD・Eが本番のB・Cと同じ列になるかは、学習開始後に最初の更新で確かめる。
- lossの曲線はGPUで値が変わる：同じF0・同じ区間でも、RTX A4000では区間ごとのlossがRTX PRO 4500と中央値で0.021ずれた（200区間中119区間で0.01以上）。以前の結果と比べるときはRTX PRO 4500で計算する。

## 固定した200区間でのloss（D、2026-10-30）

SAM2 repo `runs/short_clip/diag_loss_curve_p0/`（`scripts/loss_fixed_clips.py`、RTX PRO 4500）。F0の値は前回の `diag_loss_curve` と200区間・2種類のlossとも完全に一致。値はF0との区間ごとの差の中央値（負＝F0より低い）。

| モデル | mix（学習の目的） | box（評価に近い） |
|---|---|---|
| P0 | +0.116 | +0.135 |
| D 2 epoch | +0.004 | +0.035 |
| D 10 epoch | −0.014 | −0.001 |
| D 22 epoch | −0.016 | −0.003 |
| 参考：B 22 epoch（前回） | −0.051 | −0.038 |

- DはP0から約0.13下がり（mix、区間の80%でP0より低い）、2 epochでほぼF0の水準に届いた。その後の低下は小さく、22 epochでも前回のB（F0から）より高い。
- 区間ごとの差の中央値と、区間を単位にしたbootstrapの95%区間（5,000回）：

| 比較 | mix | box |
|---|---|---|
| D22−P0 | −0.134 [−0.164, −0.091]（−9.4%、80%の区間で低い） | −0.148 [−0.176, −0.110]（−12.4%） |
| D2−P0 | −0.083 [−0.115, −0.063] | −0.113 [−0.136, −0.090] |
| D22−D2 | −0.018 [−0.034, −0.011]（−2.4%） | −0.025 [−0.042, −0.013] |
| D22−D10 | −0.007 [−0.011, −0.002] | −0.004 [−0.009, −0.001] |
| D22−F0 | −0.016 [−0.037, −0.002] | −0.003 [−0.029, +0.027] |
| D22−B22 | +0.019 [+0.006, +0.037] | +0.025 [+0.009, +0.053] |
| 参考：B22−F0 | −0.051 [−0.067, −0.033] | −0.038 [−0.060, −0.027] |

- trainの動画から取った区間（学習には使っていない区間だが、動画は学習に使った）なので、train分布へのあてはまりを見る値で、valでの性能を直接示すものではない。
- デコーダだけの学習では、P0から始めてもF0から始めたBの水準まで下がらない。F0で学習した固定部分（Memory Attentionなど）の差が残っていると考えられる（解釈、未検証）。
