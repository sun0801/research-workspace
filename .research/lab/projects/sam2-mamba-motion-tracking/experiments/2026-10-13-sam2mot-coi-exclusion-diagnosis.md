## 解釈（暫定）

- **誤除外は全体では少ないが、Stage 2 に集中している。** Stage 1（logit 差 > 2.0）の誤除外は 2.3% で、判定はほぼ正しい。一方、logit 差が2以下で分散により判定する Stage 2 では誤除外が 56.9% で、どちらを B にするかを五分五分で決めるのと変わらない。誤除外率全体（16.7%）が中間にとどまるのは、正しい Stage 1 の判定が多数を占めるためである
- **判定の揺れは乗り移りと結びついている（H1b）。** 乗り移りが続いたエピソードでは、同じ衝突の中で B が入れ替わる割合が約3倍。Stage 2 が五分五分で判定していることと整合する（hypothesis）
- **正しく除外されたトラックも、ほとんど元に戻らない（H2 の経路）。** 正除外エピソードの 54/57 で B は本来の人物に戻らず、半数近く（25件）で除外が続いてマスクメモリが keyframe だけになっていた。ただし「戻らない」には、B がもともと重複・誤追跡でそのまま消えるのが望ましいケースも含まれうるため、これだけで H2 を支持とは言えない
- AssA が上がった対照の 0014 でも誤除外率は 25% と低くない。誤除外の多さだけで系列ごとの AssA の増減は説明できない
- 判定不能が 36%（843 / 2,348）あり、その過半が lost 状態のトラックを含む。lost のトラックは出力 box がないため本来の人物が求まりにくい。結論はこの母集団の外の衝突には及ばない

## ステップ3: オラクル CoI による介入（2026-10-14、**診断専用。性能値として報告しない**）

spec のステップ3（2026-10-14 改訂後の実装詳細と読み方）に従って実施した。オラクルは GT で CoI の判定を差し替えるため、ここに出る HOTA・AssA は再現の性能値ではない。

### 判断: **判定できた誤除外は、AssA 低下の主因とは言えない**

| 指標（3系列 0019・0063・0026 の COMBINED、TrackEval AssA） | 値 |
|---|---|
| S2 / S3（GPU 0） | 54.05 / 41.45（差 12.60） |
| オラクル | 45.16 → **回復率 29.5%** |
| S3（GPU 1、ノイズ） | 50.45 → **ノイズの回復率 71.5%**（ノイズ幅 71.5%） |

spec の読み方では「オラクルの回復率 < 20%、**またはノイズ幅の2倍未満** → 判定できた誤除外は主因ではない」。回復率 29.5% はノイズ幅の2倍（143%）を大きく下回るので、この区分に当たる。spec のとおり、これは H2 を支持したことを意味しない。オラクルが入れ替えられるのは判定できた誤除外だけで、判定不能の衝突（下記、全衝突の33%）による寄与と H2 は、本 spec の範囲では区別できない。

**ただし最大の発見はノイズの大きさである。** 判定に使った3系列では、計算誤差だけ（GPU 1 で同じコード・設定）で S3 の AssA が 41.45 → 50.45 と 9.0 ポイント動き、S2 → S3 の低下（12.6）の71%に当たる。系列別では 0019 が 43.69 → 55.23（+11.5）、0063 が 42.09 → 48.63（+6.5）。これらの系列は S2 → S3 で AssA が最も大きく下がった系列として選んだもので、その低下の大部分は CoI の系統的な効果ではなく、混雑系列での追跡の不安定さ（小さな数値差で ID の取り違えが連鎖する）による可能性が高い（hypothesis）。val 全体の CoI による AssA 低下（−1.16）と test（−2.0）は25・35系列の集計なので、系列ごとのばらつきは平均化されている。

- 3系列の HOTA はオラクルで S3 より上がった（54.15 → 56.21）が、回復率がノイズ幅の2倍未満なので、主因の判断には使わない

### 解釈と次（ユーザーの判断が必要）

- 判定できた誤除外を GT で取り除いても、3系列の AssA の低下はノイズ幅と比べて小さくしか戻らなかった。判定の誤り（Stage 2 が五分五分）だけで CoI の AssA 不足を説明できるとは言えない
- 一方で、**系列単位の AssA は数値誤差だけで ±10 ポイント近く動く**。ステップ1・2で注目した「AssA が大きく下がった系列」は、この不安定さで選ばれた可能性が高く、系列を絞った分析はこのノイズに埋もれやすい
- spec が「結果が境界付近のとき追加を検討」としていた **val 25系列でのオラクル実行**（選び方の偏りをなくせる。S3 で約2.6時間）や、ノイズ幅の測定を複数回にすることは、本 spec の範囲外として着手していない。CoI の AssA 不足（val −1.16、test −2.0）を追うなら、25系列単位で比べる設計に切り替える必要がある
- 「Stage 2 では除外しない」案（GT を使わず、性能値として報告できる）も、25系列で評価するなら候補になる。いずれも別途承認が必要
