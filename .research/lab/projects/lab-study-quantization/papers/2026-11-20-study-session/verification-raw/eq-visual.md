### (3) 構造の詳細（全 AlternateContent: A 8個，B 12個，C 7個）

- Choice と Fallback が対．Choice に `Requires="a14"`，a14 は Choice 上で宣言，mc/m/a/p/r は AlternateContent 上で宣言済み．名前空間は有効
- Choice 内は `p:sp` > `a:p` > `a14:m` > `m:oMathPara`（1個ずつ）．PowerPoint が自分で書く形と同じ
- Fallback は `p:pic`．`r:embed` は全て slide の rels に存在し，Target の media も zip 内に存在
- cNvPr の id と name が Choice と Fallback で一致．Fallback を除いた id は各スライド内で重複なし（Fallback を数えると重複に見えるが，これは対の同一 id で正しい）
- `m:r` 内の順序: `m:rPr`（あれば）→ `a:rPr` → `m:t`．全 m:r で正しい（逸脱 0）
- `m:d` の `m:dPr` や `m:f` の `m:fPr` の要素順に異常なし（目視）
- 数式サイズ: 26〜46pt（A 26〜34，B 30〜44，C 34〜46）

### (6) 枚数・ノート・句点

- 本編45枚: A/B/C とも本編45＋補足（A 8，B 9，C 10）．PDF ページ数と一致

## PowerPoint で確認すべき枚の一覧

実機で見る点: (a) 開いたときに「修復」が出ないか，(b) 数式が数式として編集でき，大きさが指定どおり（分数が小さくならない）か，(c) 零幅スペースが□や空白で出ないか．

| 優先 | 枚 | 理由 |
|---|---|---|
| 高 | A9, B9, C12 | 主役の2式＋条件．大きさと配置の最終確認．A9/C12 は零幅スペースあり |
| 高 | B26, B34 | 分数・添字が最も多く，LibreOffice で小さく見えた |
| 中 | A25, A35, B11, C13, C35 | 分数入りの式．A35 は式と表の間隔 |
| 中 | A33, B32, C33 | ∂⌊y⌉/∂y の丸め記号の描画 |
| 低 | B8 | 2^b のみ |

Fallback 画像は，PowerPoint が a14 を解釈できる場合は使われない．古い版や Keynote・Google スライドでは Fallback 画像が出るため，Fallback 画像の見た目も1枚（例: A9）は開いて確認するとよい（今回，Fallback 画像そのものは目視していない）．
