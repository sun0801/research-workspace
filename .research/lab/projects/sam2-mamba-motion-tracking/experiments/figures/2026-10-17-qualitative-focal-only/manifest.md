# 局所パターンの定性比較動画（注目する人物だけを描画, 2026-10-17）

ユーザーの依頼（局所的にうまくいっている例・いっていない例は、対象の ID と GT だけを描いた3手法の動画にする）で作った。推論結果・色・切り出し範囲・速さ（10fps = 半分の速さ）は[1回目](../2026-10-12-qualitative-patterns/)・[2回目](../2026-10-17-qualitative-patterns-v2/manifest.md)と同じ。新しい推論はしていない。

- 生成: `render_focal_only.py`（1回目の `render_videos.py` の描画関数を使う）。OpenCV のある python（samurai 環境）で実行した。
- 各手法の動画に描くのは次だけ（ほかの人の枠は描かない）。
  - 注目する人物の GT（白い破線枠）
  - その手法で、窓の最初の10フレームにこの人物と最も多く対応した track（IoU 0.5 以上）。その後どこへ行っても描く
  - そのフレームでこの人物に重なっているほかの track（IoU 0.5 以上）

## ④ の作り直し（`*-target.mp4`）

ユーザーの指摘（④ の動画が見にくい。手元の版の「局所的にうまくいっている例」＝10/08 の dancetrack0034 動画と同じように、対象の ID と緑の GT 枠だけを描く）で、`render_target_only.py` で作り直し、再構成版の④に入れた。

- 縦長（500×660）に、注目する人物（GT 8）の周辺を切り出した（元画像で 272×360 の範囲を拡大）。10fps。
- 描くのは、GT の枠（緑、ラベルなし）と、その手法でこの人物を追っている track の枠（水色、全手法で同じ色、ラベルは track の番号）だけ。
- 追っている track は SAMURAI・Ours が ID 8、SAM2 が ID 4。SAM2 の track 8 は frame 466 以降、画面右端（x≈1720）の別の人に付いているため、ID 8 だけを描くと SAM2 の枠が切り出しの外に出て何も映らない。そこで SAM2 だけ、この人物を追っている ID 4 を描いた（スライドにも明記）。
- ポスター画像は frame 852（Ours が見失っている途中）。

## ④ を dancetrack0007 GT 1 に差し替え（`localfail0007-*-target.mp4`）

0079 GT 8 の版は、Ours の ID 8 の枠が崩れて画面の外まで広がるだけで、うまくいっていないことが見て分かりにくかった（ユーザーの指摘）。「切り出した画面の中で、ほかの手法は GT と同じ人に付いているのに、Ours だけ別の人に移る」例を `search_ours_switch.py` で探した。

- 探し方: 各 GT 人物について、直前30フレームで最も多く対応した track を各手法の「自分の track」とし、Ours の自分の track が隣の別の GT 人物と IoU 0.5 以上で重なり、同じフレームで SAM2・SAMURAI の自分の track はこの人物と重なっているフレームが6フレーム以上続く区間を、val 25系列から探した。
- 見つかった区間（長い順）: 0004 GT 2（27フレーム）、0030 GT 1（23）、0034 GT 10（21、補足④(2)と同じ）、0035 GT 0（20）、0019 GT 2（18）、0026 GT 11（12）、0007 GT 1（12）ほか。
- 3手法とも自分の track の番号が GT と同じ（ID 1）で、切り出しの中で移った先の人が見える 0007 GT 1 を選んだ。
- frame 370–415（46フレーム、10fps で4.6秒）。Ours の ID 1 は frame 377 から 423 まで左隣の人（GT 6）に付く。SAM2・SAMURAI の ID 1 はこの人物に付いたまま（frame 394–405 は枠が小さくなり IoU が 0.5 を下回るが、同じ人物の上にある）。
- 切り出しは、GT と各手法の ID 1 の枠が入る範囲（崩れて大きくなった枠は除く）を縦長 500×660 にした。
- 0079 GT 8 の `*-target.mp4` はファイルとして残す（スライドでは使わない）。
