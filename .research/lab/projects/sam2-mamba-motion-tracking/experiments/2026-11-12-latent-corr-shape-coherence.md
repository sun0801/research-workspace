# A-b の対応で形が崩れる程度の計測（11/6 MTG の指摘）

11/6 MTG の指摘：「類似度が一番高い位置に運ぶ方式では、ちょっとしたノイズで、あるマスの隣のマスがまったく違うところに行く（形が崩れる）」。これが、学習・評価で使った A-b の対応で、どれくらい起きているかを測った。学習はしていない。SAM2 repo のコードは変えていない（段階0の関数を読み取りだけで使った）。

スクリプト・データ・図：[figures/2026-11-12-latent-corr-shape-coherence/](figures/2026-11-12-latent-corr-shape-coherence/)（コマンドは [manifest.md](figures/2026-11-12-latent-corr-shape-coherence/manifest.md)）。

## 結論

- **A-b の対応は、物体の外形は保つが、物体の内側の並びは崩れている。**
  - 隣のマスと移動が1マス以上違う辺の割合は、A-b が 33%（遅い 19%・中くらい 35%・速い 45%）。RAFT は 4%（0.4%・3%・7%）。
  - 移動先が折り返す（隣どうしが交差する）マスの割合は、A-b が 17%（9%・19%・23%）。RAFT は 2%。
  - 一方、前のフレームの物体のマスクを運んだときの正解との IoU は、A-b が 0.76 で、RAFT（0.67）・同じ位置（0.58）より高い。速い層では A-b 0.74、RAFT 0.56、同じ位置 0.43。
- **A-b の移動は、平均すると RAFT から「動かさない」のと同じくらい離れている。** RAFT の移動との差（マス）は、A-b 1.54・同じ位置 1.58。遅い層（A-b 0.68・同じ位置 0.46）と中くらいの層（1.35・1.19）では、A-b の方が動かさないより RAFT から遠い。速い層だけ A-b が近い（2.61・3.10）。
- **softmax（τ=0.02）は、argmax より折り返しが少ないが、隣とのずれは同程度。** 折り返し 17% と 39%、隣と1マス以上ずれる辺 33% と 30%。
- **state の複製も同じ程度に起きている。** 前のフレームの物体のマスのうち、1.5マス分より多く配られるマス（列の和 > 1.5）は 19%（13%・21%・24%）。段階0の中速の値（0.19）と同じ程度。
- 解釈（未確認）：A-b の対応は「どの物体から持ってくるか」は当てるが、「物体のどの位置から持ってくるか」は当てていない。似た見た目のマスが物体の中にたくさんあり、最も似たマスがばらばらな位置に散る、と見ている。マスクの IoU は前者だけを見るので高く出る。改善では、同一物体率を保ったまま、移動を隣どうしで揃える制約を入れるのが筋と考える。

## 方法

- **対象**：MOSE train の tuning 125動画（A-b を評価したのと同じ動画）、tuning_object_motion.jsonl の物体。各動画で、等間隔に最大12組の連続フレーム（t−1 → t）を取った。物体が t で1マス以上（被覆率 0.5 以上で最大の物体）あり、t−1 で見えている組を使った。3,185組（物体×組）、310物体（遅い 104・中くらい 103・速い 103。区切りは評価と同じ 0.620・1.233 マス/フレーム）。
- **対応**（A-b の学習・評価と同じ設定）：F0 の画像エンコーダの stride 16 特徴（64×64・256ch）、cos 類似度、15×15 の窓（±7マス）。
  - A-b：softmax、τ=0.02
  - argmax：類似度が最大の1マス
  - identity：同じ位置（今の V3）
  - RAFT（参照）：torchvision の RAFT large（公式の重み、更新12回）。SAM2 と同じ 1024×1024 の入力で、t から t−1 への flow を計算し、16×16 の各マスで平均して16で割った。正解の動きではなく、参照として使う。
- **各マスの移動** u(p)：A-b の state の運び方 h'(p) = Σ_q W(p, q) h(q) と同じ向きで、「t のマス p が、t−1 のどこから持ってくるか」の期待値（マス単位）。RAFT は flow そのもの。
  - 符号の確認：画像を右に2マスずらした合成の組で、softmax・RAFT とも中央値で (dy, dx) = (0, −2) を返した。
- **指標**（目標のマス = t の物体のマス）：
  - 隣と1マス以上ずれる辺の割合：目標の中の上下左右の隣どうしで ‖u(p) − u(p')‖ > 1 の割合
  - 隣との差の平均（マス）
  - 折り返しの割合：p + u(p) の写像のヤコビアンの行列式が 0 以下のマスの割合（前進差分、p・右・下が目標の中にあるマス）
  - 運んだマスクの IoU：t−1 の物体の被覆率を W で運び（RAFT は p + u(p) で双線形補間）、0.5 以上を正解の t のマスと比べる（画面全体）
  - RAFT との差：目標の中の ‖u − u_RAFT‖ の平均
- **集計**：物体ごとに組の平均を取り、速さの層で物体の平均。区間は物体の bootstrap 95%（10,000回、seed 123）。

## 注意

- RAFT は正解の動きではない。マスの平均で物体の縁の背景の flow が混ざる。運んだマスクの IoU が A-b より低いのは、縁で背景の動き（ほぼ0）が混ざることと、被覆率の双線形補間でマスクがぼやけることによる可能性がある（未確認）。隣とのずれ・折り返しは、実際の物体の動きが物体の中で滑らかなことを前提にした目安。
- 回転・変形・拡大する物体では、正しい動きでも隣どうしの移動は少し違う。1マスの閾値は仮に決めた。
- 物体の中の並びが崩れることが、性能にどれだけ効くかは測っていない。物体の中の state が似ていれば、並びが崩れても影響は小さいかもしれない。
- 組は各動画で最大12組の等間隔。最初のフレームの直後（t=1）の組も含む。
