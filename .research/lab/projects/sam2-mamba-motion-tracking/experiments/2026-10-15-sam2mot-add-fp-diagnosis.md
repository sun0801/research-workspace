# SAM2MOT再現 Object Addition 以降の FP の中身（val 25系列、読み取り専用の診断）

## 目的

CodaBench の採点ログ（`2026-10-09-sam2mot-test-runs.md` の 2026-10-15 追記）から、論文との MOTA の差は FP が多いことでしか説明できないと分かった。test は GT がないので、val で FP の中身を分類する。追跡コードは変更せず、既存の出力を GT に対応づけて数えるだけの診断（GT は解析だけに使う）。

## 方法

- 対象: val 25系列、3x_coco 主設定の S1（`s1_baseline`）・S2（`s2_addition`）・S3（`s3_coi_no_lowconf`）・S4（`s4_qr_refine`）
- 対応づけ: TrackEval CLEAR と同じ（IoU ≥ 0.5 の Hungarian、直前フレームと同じ組を優先）。4 run × 25系列で FN・FP・IDSW が TrackEval と一致した
- FP box の分類（上から順に当てはめる）

| 分類 | 定義 | 意味 |
|---|---|---|
| 重複（dup） | 他の出力にマッチ済みの GT と IoU ≥ 0.5 | 同じ人物を2本のトラックが追っている |
| 位置ずれ（loc） | どの出力にもマッチしていない GT と IoU ≥ 0.1 | その人物を追っているが box がずれている。同じ GT が FN にもなる |
| 部分重なり（partial） | マッチ済みの GT と IoU 0.1〜0.5 | 他の人物に部分的に重なる |
| 背景（bg） | どの GT とも IoU < 0.1 | 人物のいない場所 |

- スクリプト: 実装リポジトリ `sam2mot_repro/scripts/diag_add_fp.py`、実行ログ `sam2mot_repro/logs/diag_add_fp.md`、結果 `results/diag/add_fp/s1_s4.{json,md}`

## 解釈（暫定）

- **Add が重複を作るわけではない。** Add で生まれたトラックのうち、生まれた時点で既存トラックと同じ人物に重なったものは 250 本中 2 本だけだった。`test-runs` の 2026-10-15 追記で立てた「Add で同じ人物に新しいトラックを重ねて追加している」という仮説は、val では否定された。
- **Add で増える FP の 65% は、生まれた後の重複**（トラックが隣の人物に乗り移り、2本が同じ人物を追う状態）。重複は Add のない S1 でもすでに 16,868 件ある。Add で追うトラックが増えると、乗り移った先の人物もすでに追われている場合が増え、重複になると考えられる（hypothesis）。
- **CoI は重複をほぼ取り除く**（43,556 → 7,055、−84%）。CoI の MOTA 寄与が論文と一致すること（val +17.10、test +17.9、論文 +17.7）と整合する。
- **CoI の後に残る FP の最大要因は位置ずれ**（S3 で 46%）。位置ずれは FP と FN が対になるので、val S3 では位置ずれだけで MOTA を約 11.9（5.9 × 2）下げている。位置ずれの 9 割は「出力 box が GT より小さい」もので、人物どうしが重なる場面に偏る。マスクが見えている部分だけを覆い、box が隠れた部分を含む GT より小さくなっている可能性が高い（hypothesis）。
- 論文も Limitation で「box は見えている領域しか覆わない」と述べているので、同じ現象は論文の実装にもあるはずだ。論文との差がこの現象の頻度の違いから来ているのかは、この診断では分からない。A3（mask→box、全連結成分の外接矩形）の代替案「最大成分のみ」にすると box はさらに小さくなるので、位置ずれは減らない見込み。
- Q-R（S4）は位置ずれを少し減らす（13,367 → 12,368）が、重複が少し増える（7,055 → 8,359）。

## 次の候補（未実施、ユーザーの判断が必要）

1. 位置ずれの FN・FP の対が、test の MOTA の差（−8〜9）をどこまで説明するかを見積もる。test は GT がないので、val の比率をあてはめるだけの概算になる
2. 位置ずれを減らす方向の比較（新しい spec が必要。論文からの変更になる）。例: 高信頼の検出とマッチしたフレームでは、出力 box に検出 box を使う
3. Add の寄与不足（test）の切り分けはここで区切り、CoI の深追いと合わせて「続けるか／区切るか」を MTG で相談する

## 追記 2026-10-15: 位置ずれが test の MOTA の差をどこまで説明するか（概算）

test には GT がないので、val の比率を test の FP・FN にあてはめた概算。位置ずれの FP が対応する GT（FN 側）の数は、`diag_add_fp.py` に集計を足して求めた（`loc_gt`。ほかの列の値は変わらない）。

### val の比率

| 段 | 位置ずれ FP / 全 FP | 位置ずれの GT / 全 FN | 位置ずれ FP / 位置ずれの GT | val で位置ずれが下げている MOTA |
|---|---|---|---|---|
| S3 | 13,367 / 28,856 = 46.3% | 12,164 / 22,366 = 54.4% | 1.10 | 11.3 |
| S4 | 12,368 / 29,010 = 42.6% | 11,187 / 21,473 = 52.1% | 1.11 | 10.5 |

### test への当てはめ

FP 側と FN 側のどちらの比率を使うかで値が変わるので、範囲で示す。

- 下限: FN 側の比率を使い、位置ずれの GT を出してから、FP をその 1.1 倍とする
- 上限: FP 側の比率を使い、位置ずれの FP を出してから、GT をその 1/1.1 とする

| 段 | 位置ずれが下げている MOTA（推定） | 論文との MOTA の差 | 本再現 test の誤り計 | 位置ずれを除いた誤り計（推定） | 論文 test の誤り計 |
|---|---|---|---|---|---|
| S3 | 7.1〜12.6 | −8.2 | 20.8 | 8.2〜13.7 | 12.6 |
| S4 | 6.7〜11.1 | −9.3 | 20.1 | 9.0〜13.4 | 10.8 |

誤り計は GT box 数に対する FN + FP + IDSW の割合（%）で、100 − MOTA と同じ。

### 解釈（暫定）

- **位置ずれは、論文との MOTA の差（8〜9）と同じくらいの大きさがある。** 位置ずれをすべて除くと、本再現の誤り計は論文と同じ水準（S3 で 8.2〜13.7 と 12.6）になる。
- ただし、論文も Limitation で同じ現象を述べているので、論文の位置ずれが 0 とは考えにくい。差のすべてを位置ずれで説明するには、論文の位置ずれが本再現の多くて3.5割程度でなければならない（S3 で上限 12.6 なら 4.4 / 12.6 ≈ 3.5割。下限 7.1 なら差 8.2 より小さく、位置ずれだけでは説明しきれない）。これが成り立つかどうかは、論文の box の作り方が分からないので判断できない。
- 言えるのは「CoI の後に残る論文との差は、主に位置ずれの FP・FN の対で説明できる規模で、重複・背景（Add や CoI の判定）が主因ではない」まで。
- 前提: val と test で位置ずれの割合が同じだとしている。val の S2〜S4 では割合はほぼ一定（FP の 43〜46%、FN の 48〜54%）だが、test の系列で同じとは限らない。
