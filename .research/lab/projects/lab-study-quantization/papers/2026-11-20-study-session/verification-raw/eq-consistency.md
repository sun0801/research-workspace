# 検査② 数式・数値の整合（2026-11-16，数式オブジェクト置換後）

検査者: 作者ではない検査者．スライド・ノートは編集していない．

## 方法

- OMML: 各 pptx の `a14:m` から `m:t` と構造（分数・添字・括弧種・アクセント）を読み出し，build_{a,b,c}.py の LaTeX と照合した（A: 9,25,33,35／B: 8,9,11,26,32,34／C: 12,13,33,35）．
- Fallback 画像: 同じ枚の `mc:Fallback` の画像を全て取り出して目視した（22個）．LaTeX の descr とも一致を確認した．
- 原典: Nagel 白書 式(4)(6)(7)(8c)(11)(12)(36) を pdftotext と PDF 画像（p5, p6）で，Jacob 式(1)(12)(14)，SmoothQuant 式(3)(4) を pdftotext で確認した．
- 置換前後: pptx は .gitignore で HEAD に無いため，HEAD の build_*.py の diff と、HEAD の作者メモで比べた．
- 数値: Python で再計算した．ハンズオンは `quant/core.py`，`ex1_tensor.py`，README を読んだ．

## 結論（要約）

- 式そのものの OMML／LaTeX／Fallback／原典の食い違いは見つからなかった．q_max の符号，2^(b−1)，α と 1−α，σ² と ε は全て正しい．
- 計算例の数値は全て再計算と一致した．
- 必須修正 2 件（B 1 件，C 1 件）．いずれも式の誤りではなく記号の定義の不整合．
