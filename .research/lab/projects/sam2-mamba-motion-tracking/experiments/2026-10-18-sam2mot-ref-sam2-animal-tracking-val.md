# SAM2MOT再現 第三者の再実装（SAM2-Animal-Tracking）を DanceTrack val で回した参考比較

spec: `specs/2026-10-18-sam2mot-ref-sam2-animal-tracking-val-spec.md`。実行の事実は実装リポジトリ `sam2mot_repro/logs/ref_sam2animal_val25.md`。
**第三者の再実装による参考比較で、本再現の性能値でも SAM2MOT の再現値でもない。**

## 条件

- 第三者の実装: `ecker-lab/SAM2-Animal-Tracking`（HEAD `b02af23`、arXiv 2511.02591）。改変は offload の1か所のみ（保存先の変更）
- 検出: 本再現と同じ o365tococo 検出を変換して読み込み（score ≥ 0.1）
- GPU: RTX A4000、torch 2.12.0+cu130。本再現 S4 は Blackwell（GPU 差のノイズは HOTA 0.15 程度）
- R1: 第三者の既定（系列ごとの自動閾値、マスクによる追加判定、マスク NMS、Q-R はトラックの作り直し など）
- R2: R1 から自動閾値だけ外す（高信頼の閾値 0.5 固定）

## 判定（spec の基準）

| 基準 | 値 | 判定 |
|---|---|---|
| R1 が本再現 S4 より HOTA +0.5 以上 | −0.20 | 当たらない（±0.5 以内） |
| R1 − R2 が HOTA +0.5 以上 | +0.29 | 当たらない |

→ spec に従い、**第三者の設計変更は DanceTrack val の HOTA を上げない**と記録する。自動閾値も HOTA では効果が確認できなかった。本再現の主設定は変えない。

## 解釈（暫定）

- **HOTA は同じでも、中身は違う。** 第三者の実装は DetA・MOTA が高く（+2.7 / +3.6）、AssA が低い（−2.7）。FP・FN とも少ないが、出力 ID が多く（491 / 404）、1人の GT が複数の ID に分かれやすい（AssRe −3.4）。
- **重複の FP は第三者の実装で 3 分の 1 になる**（7,053 → 2,421）。マスク NMS か、マスクによる追加判定が効いていると考えられる（どちらかは切り分けていない）。本再現 val の MOTA が論文より低い原因の一部は、重複の残りにある可能性がある。
- **位置ずれの FP は第三者の実装でも同じだけ残る**（11,808 → 12,225）。出力 box をマスクから作る限り、位置ずれは実装によらず出る。`2026-10-15-sam2mot-add-fp-diagnosis.md` の「残る差の主因は位置ずれ」という結論と整合し、本再現の実装の誤りではない可能性が高まった。
- **自動閾値は val では FP を減らし MOTA を上げる（+1.6）が、HOTA はほぼ動かない。** test で Add の寄与が論文の半分しかないことを自動閾値で説明できるかは、この結果からは分からない（論文の系列別閾値は手で選んだもので、自動閾値と同じとは限らない）。
- 第三者の実装も、本再現も、val の HOTA は 69 前後で並ぶ。独立した2つの再実装が同じ水準に収まったことは、本再現の到達点（val S4 69.3、test 70.6〜71 程度）が、論文の記述から作れる実装としては妥当な水準であることを示唆する（hypothesis）。

## 次（ユーザーの判断が必要）

1. ここで SAM2MOT の深追いを区切り、「論文の記述からの再現では val HOTA 69 前後。残る差は box の位置ずれと、論文の系列別の閾値（未公開）」と MTG で報告する
2. 重複を減らす要素（マスク NMS／マスクによる追加判定）を本再現に入れた比較を行う（新しい spec。論文からの変更）。MOTA は上がる見込みだが、HOTA が上がるかは R1 の結果からは期待しにくい
