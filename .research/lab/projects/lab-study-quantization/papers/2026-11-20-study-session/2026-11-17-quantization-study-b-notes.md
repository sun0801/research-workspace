# B案（問題駆動型）作者メモ（検査①〜⑤を受けた改訂版）

- スライド: `2026-11-17-quantization-study-b.pptx` / `.pdf`（作成スクリプト `tools/build_b.py`，図は `tools/make_figs_b.py` と `tools/make_fig_act_b.py`）
- 枚数: 全54枚 = 本編45枚（タイトル1，節の扉5，内容39）＋付録9枚（扉1，全比較表4，層ごとの感度1，NF4 1，原典の高速化1，ViT・拡散モデル1）。本編の全スライドと付録にノートあり
- 自分の確認: render 後に本編45枚を画像で目視確認し，`check_overflow.py` は OVERFLOW 0

## 案の特徴

- 3つの困りごと（14B が載らない / エッジで動かしたい / 速くしたい）から入り，各区間の入口（扉の副題）に「問い」を置く
- 速度の結論（量子化すれば速くなるとは限らない）を導入4枚目で先に見せ，演習④（38〜39枚付近）で理由を回収する。4枚目の下に weight-only / dynamic / FX / kernel の定義を置いた
- 区間と演習は spec の時間割に合わせた: 10–28 概念＋①，28–45 粒度と外れ値＋②，45–62 活性と較正＋③，62–80 PTQ・QAT(STE)・SmoothQuant・分類表＋④，80–90 まとめ。演習①②③は各区間の中でその場で回し，62–80 の最後に「演習②③の追加条件」（2分）を置いた
- 外れ値は 28–45 に置いた: LLM の外れ値（原典）→ DeiT-Tiny の測定（実測）の順。A4 の崩れ（45–62）で「外れ値だけでは説明できない」に戻る
