## Doc（流れの案）から変えた点

原典を読んだ結果、[英論文紹介の Doc](https://claude.ai/artifact/S5PX9BN7Mi2VkeDF9vGCL1) の流れから次の点を変えた。

- **TS-Mamba は「軌跡で運ぶ」ではなく「軌跡で集める」**。TS-Mamba はフレームをまたいで SSM の state を持ち越さない。毎フレーム、軌跡に沿って過去の token を集め、その系列を scan する。
- **Memory as Dynamics の gate が止めるのは「予測の使用」**。Mamba2 は直近8フレームの窓で毎時刻作り直していて、持ち越す state がない。論文の「汚染」は SAM2 の memory bank の汚染で、SSM の state の汚染ではない。
- **TV3S の Table 3 は state の有無の比較ではない**（3行とも state を持ち越している）。state の効果は、Table 6 の過去フレーム数の比較で見せる形にした。
- 上の3点から、まとめに「SSM の state を長く持ち越すのは TV3S だけ。後半2本は長期の情報を明示的な memory に置き、SSM は短い系列で使う」という整理を入れた（発表者の解釈として明記）。

- 同じ理由で、ロードマップ（各論文の扉と概要に出す4段の帯）の表記を「TV3S：位置で持ち越す」「TS-Mamba：軌跡で集める」にした。
