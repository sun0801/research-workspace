# 2026-07-30 MTG 議事録

## 会議情報

- 日時: 2026-07-30
- 参加者: ユーザー、指導教員
- プロジェクト: sam2-mamba-motion-tracking

## やったこと

- SAM2 tiny、DanceTrack val 25系列、state carry条件で、epoch100 checkpointと元repoの`best_tracking_hota.pth`（metadata上epoch20）を比較した。
  - epoch100: HOTA 55.520、DetA 49.601、AssA 62.482、MOTA 36.587、IDF1 64.154、IDSW 1,535
  - best-HOTA: HOTA 54.606、DetA 48.609、AssA 61.691、MOTA 34.595、IDF1 62.813、IDSW 1,525
  - epoch100は主要指標で高かったが、IDSWのみbest-HOTA checkpointが10少なかった。
- `kf_score_weight` を変更し、SAM候補IoUとMamba予測bbox IoUの重みの影響を確認した。0.0 / 0.25 / 0.5を比較し、0.0と0.5のHOTA差は0.004だった。
- Codexで追跡結果の候補を抽出し、既存の可視化アプリでMIRUポスター向けの定性候補を確認した。共通25系列から自動候補30件を抽出し、`dancetrack0034 / GT ID 9`、`dancetrack0034 / GT ID 7`、`dancetrack0007 / GT ID 6`、`dancetrack0081 / GT ID 12`を主候補として整理した。
- MIRUでの発表方法として、30 FPSの動画を流し、詳細説明時には追跡結果可視化アプリを使う案を検討した。

## 話したこと

### Checkpoint・評価設定

- 元repoのvalidation HOTAで選ばれたcheckpointが、SAM2へ統合したときの最良checkpointになるとは限らない。
- epoch100とbest-HOTAの2点比較だけではSAM2上の最適epochは決められないため、必要に応じてDanceTrack valをepochごとに評価し、checkpoint選択の推移を確認する。
- `kf_score_weight` は今回の25系列ではHOTA差が小さく、細かい重み探索を主要な改善課題として扱う根拠は弱い。一方、AssA / IDF1とMOTA / IDSWで傾向が異なるため、単一指標だけで最適値を断定しない。

### 定性的評価・MIRU

- 定性候補は、statefulの良い結果を先に選ぶのではなく、ベースラインの失敗・不安定化とstatefulの継続を同じsequence・対象・フレーム区間で対応付ける方針で抽出した。
- 自動ランキングは候補を絞る補助として有効だが、最終的にはViewerで対象の消失、ID切替、box位置ずれ、遮蔽や対象交差を確認する必要がある。
- 今後は手法間の差分が大きい区間をランキングして可視化できる専用ツールを作ると、候補選定を再現しやすい。
- MIRUでは、SAM2 / SAMURAI / 提案手法を動画で示し、ポスターに掲載した定性的結果やIDの説明時に可視化アプリを併用する案を検討した。4分割で4手法を表示する案も出たが、最終レイアウトは未確定。
- MIRUで確認・相談したい事項として、Mambaのhidden state contamination、MOTにおける定性評価の代表sequenceの選び方、追跡結果の見せ方を整理した。

### MambaTrack・state carry学習

- MambaTrackは、論文に近い性能まで再現できるかを確認する必要がある。現状のDetAなどの低さや、検出入力・MOT評価条件の違いを含めて、他手法と比較可能な評価経路を整える。
- state carry型は、sliding windowで学習したモデルを推論時だけstate carryにするのではなく、recurrentな学習、teacher forcing / free running、TBPTTなどを含めて学習方法そのものを見直す必要がある。
- ポスター・論文の定量表は、関連論文の表記を確認し、有効数字・小数桁を揃える。

## 決定事項

- SAM2統合の現時点の暫定基準はepoch100として扱う。ただし、epoch100をSAM2上の最適checkpointと断定せず、元repoのbest-HOTA checkpointも比較対象として記録する。
- `kf_score_weight` の細かい探索は主要課題として優先せず、今回の比較結果を記録したうえで、他の比較条件・学習方法の検証へ進む。
- MIRUの定性結果は、自動抽出候補をそのまま掲載決定とはせず、Viewerで人手確認したうえで採用する。
- 次の研究上の重点は、MambaTrackの論文水準の再現と、state carry型の学習方法の導入・見直しとする。
- 定量結果の表記は、関連論文と有効数字・小数桁を揃える。
