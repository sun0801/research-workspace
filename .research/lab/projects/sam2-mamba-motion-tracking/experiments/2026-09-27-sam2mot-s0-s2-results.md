# SAM2MOT再現 S0〜S2: 検出生成・baseline・Object Addition の val 25系列結果

## 目的

承認済みspec `specs/2026-09-08-sam2mot-reproduction-spec.md` の S0〜S2 を実施した結果を Research Workspace に記録する。S0〜S2 は 2026-09-10〜09-12 に実装リポジトリで実施済みだったが、workspace には未反映だった。S2 の TrackEval 評価は 2026-09-27 に実施した。

本メモは実測値の記録である。spec の成功基準（符号と順序・機構署名）は S3・S4 の結果が揃ってから判定する。

## S0: 検出生成（2026-09-10）

- val 25系列すべて成功、欠損なし。所要 4.14 h（GPU 1、約1.70 fps）
- det conf 0.5 での per-frame recall は全体 79.82%（最小 dancetrack0026 の 54.65%、最大 dancetrack0097 の 94.97%）
- GT track 273 本のうち 272 本（99.63%）が系列中に一度以上、高信頼検出とマッチする。未カバーは dancetrack0018 の track 6 のみ
- GT は recall 算出のみに使用し、検出入力には使っていない（旧 sam2mot_lite のオラクル条件は解消）

## S1: baseline（2026-09-10）

Add / CoI / Q-R はいずれも無効。Object Removal（4状態遷移）は baseline に含める。

- 25/25 系列成功、所要 1.72 h、peak VRAM 最大 10.83 GiB
- 生成トラック 167（第1フレームの高信頼検出のみで初期化）

## S2: Object Addition 追加（推論 2026-09-11〜12、評価 2026-09-27）

- 実装コミット `16562b3`。`--no-object-addition` で S1 と出力が md5 一致することを確認済み（0005 / 0018）。途中追加 0 件だった dancetrack0065 も S1 と md5 一致
- 25/25 系列成功、形式検証 25系列 PASS、所要 3.08 h、peak VRAM 最大 19.7 GiB（dancetrack0081）
- 生成トラック 417（第1フレーム 167 + 途中追加 250）。3段フィルタの通過数は 184817 → 554 → 250

## 解釈（暫定）

- 現時点で判定できる spec の基準は「Add の寄与 > 0」のみで、この条件は満たしている。CoI の寄与が Add を上回るか、Q-R が最小かという順序条件は S3・S4 の結果待ち
- Add の効果は主に検出側に出ている（FN −71380、DetA +14.38）。一方で AssA −6.39、IDSW +737、FP +41077 と association 側は悪化した。途中追加のトラックが既存トラックと重複した可能性と、ID の付け替わりが増えた可能性がある。ただし原因はまだ切り分けていない
- 論文では、IDSW を減らし AssA を上げるのは次段の Cross-object Interaction（CoI）の役割とされている。したがって S2 時点で AssA が下がっていること自体は S3 の検証対象である。S3 の機構署名（IDSW 減・AssA 増・MOTA 増・DetA ほぼ不変）は、この S2 の値を基準に確認する

## 注意

- 各段の実装セッションでは、差分の解釈と合否判定を行わないプロトコルにしている（実装リポジトリ `CLAUDE.md`）。上の解釈は workspace 側の暫定整理であり、S3 以降の結果で見直す
- S2 の smoke（1〜3系列）の実行ログは実装リポジトリの `logs/` に残っていない
- 途中追加でトラック数が増えると VRAM と所要時間も増える。S3・S4 で同時追跡数がさらに増えた場合は、32 GiB の GPU 0 に収まるかを確認する
