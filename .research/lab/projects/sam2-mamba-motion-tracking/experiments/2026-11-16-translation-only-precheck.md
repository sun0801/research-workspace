# 平行移動のみの位置合わせの事前確認（保存済みの移動場だけを使う、CPU）

11/13 MTG の決定「位置合わせ付き（平行移動のみ）の対応付けから進める」の設計を決めるために、[11/12 の計測](2026-11-12-latent-corr-shape-coherence.md)で保存した移動場（`fields.pt`）を読み直した。新しい特徴の計算・学習はしていない。GPU は使っていない。SAM2 repo のコードは変えていない。

スクリプトと出力：[figures/2026-11-16-translation-only-precheck/](figures/2026-11-16-translation-only-precheck/)（`precheck.py`、`data/summary.md`、`data/precheck.jsonl`）。図はない。

## 結論

- **物体の中の実際の動き（RAFT を参照）は、1フレームでは大半が平行移動に近い。ただし速い物体では足りない。**
  - 物体ごとに1つの平行移動を当てはめると、そこから1マスより離れるマスは全体 14%（遅い 3%・中くらい 10%・速い 28%）。
  - 20マス以上の271物体に限ると、1つの平行移動から1マスより離れるマスは 17%（3%・13%・31%）。物体ごとのアフィン変換（回転・拡大縮小を含む）まで当てはめると 10%（2%・7%・19%）に減る。
  - 周りのブロックの中央値からのずれで見ると、3×3 で 2%、5×5 で 3%、9×9 で 5%、15×15 で 8%（速い層は 4%・7%・10%・15%）。ブロックが小さいほど合う。
- **1フレームあたりの回転・拡大縮小は小さい。** アフィン変換の当てはめでは、回転は平均 2.6°（速い 3.8°）、拡大縮小は平均 4%（速い 7%）。物体の端から端までで作る移動の差は平均 1.1 マス（速い 1.9 マス）。
- **A-b の各マスの移動を物体の中で多数決するだけで、RAFT との差は A-b・動かさない場合より小さくなる。** 物体の中の中央値を1つの平行移動として使うと、RAFT との差（マスごとの平均）は 1.07 マス（遅い 0.37・中くらい 0.84・速い 2.02）。A-b は 1.54（0.68・1.35・2.61）、動かさない場合は 1.58（0.46・1.19・3.10）。遅い層でも動かさない場合を下回る。
  - ただし、RAFT の移動場に物体ごと1つの平行移動を当てはめたときの下限は 0.52（0.15・0.42・1.00）で、速い層ではまだ2倍離れている。
- **1つの平行移動で前のフレームのマスクを運ぶと、外形の一致（IoU）は A-b より低い。** 推定した平行移動で 0.66〜0.68、正解のマスクを見て選んだ最良の平行移動（上限）でも 0.70（整数マス）・0.73（0.5 マス刻み）。A-b は 0.76、動かさない場合は 0.58。物体の形が変わる分は、平行移動だけでは追えない。
- **ブロックごとの多数決（A-b の argmax の移動場の中央値フィルタ）は、ブロックを大きくするほど並びはそろうが、運んだマスクの IoU は下がる。** 隣と1マス以上ずれる辺は 3×3 で 10%、5×5 で 5%、9×9 で 2%、15×15 で 1%（A-b 33%、RAFT 4%）。IoU は 0.72・0.71・0.67・0.65。この IoU は、11/13 の訂正と同じ disocclusion の影響（後ろ向きの warp が、物体が去った背景に物体の値をコピーする）を含むので、割り引いて読む。

## 方法

- **入力**：11/12 の `fields.pt`（MOSE train の tuning 125動画、310物体、3,185組。各組に、t の物体のマス、t−1 の物体の被覆率、A-b（softmax・argmax）と RAFT のマスごとの移動 u(p)）。u(p) は「t のマス p が、t−1 のどこから持ってくるか」（マス単位）。
- **集計**：11/12 と同じ。物体ごとに組の平均、層ごとに物体の平均。区間は物体の bootstrap 95%（10,000回、seed 123）。保存した場から 11/12 の値（隣と1マス以上ずれる辺 0.332、運んだマスクの IoU 0.761・0.670・0.579）が再現することを確かめた。
- **1. 当てはまり（RAFT を参照）**：t の物体のマスで、RAFT の移動から、(a) 物体の中の中央値（1つの平行移動）、(b) k×k の窓の中の物体のマスの中央値（ブロックごとの平行移動）、(c) 物体ごとのアフィン変換（最小二乗、残差が大きいマスを除いて3回やり直す。20マス以上の物体だけ、271物体）を引いた残差。
- **2. 多数決での推定**：A-b の argmax・softmax の移動の、物体の中の中央値・最頻値を1つの平行移動とし、RAFT との差を測る。多数決の範囲は、t の正解のマス（診断用）と、A-b が運んだマスクが 0.5 以上のマス（t の正解を使わない）の2通り。
- **3. 外形**：t−1 の被覆率を1つの平行移動で動かし（双線形補間）、0.5 以上を t の正解と比べた IoU。上限として、±7マスの中で IoU が最大になる平行移動（整数、0.5 刻み）も探した。
- **4. ブロックごとの多数決**：argmax の移動場に k×k の中央値フィルタをかけた場で、11/12 と同じ指標を測る。

## 注意

- **RAFT は正解の動きではない。** 滑らかな場を出す手法なので、非剛体の動きを小さく見積もっている可能性がある。「どちらでも合わない」には、RAFT の誤りと、マスの平均で境界の背景が混ざった分も入る。
- アフィン変換の大きさは絶対値の平均なので、場のノイズの分だけ大きめに出る。
- 隣り合うフレーム（1フレーム差）だけの値。フレームが飛ぶ場合や、遮蔽の後は別。
- **この確認で測ったのは「多数決」で、本来の案（類似度を範囲の中で足してから移動を選ぶ）ではない。** 類似度の表が要るので、GPU で特徴を計算し直す段階で測る。
- 運んだマスクの IoU は、移動場で運ぶ方式（4. と RAFT）では disocclusion の影響を含む（[11/12 の訂正](2026-11-12-latent-corr-shape-coherence.md)）。物体ごとに1つの平行移動で動かす場合（2・3.）は、マスク全体をずらすだけなので、この影響はない。
- 折り返しの 11/12 の値（0.173）と今回の再計算（0.175）の差は、折り返しを測れるマスがない物体の扱いの違いによる（今回は 302 物体の平均）。
